# Proyecto de Producción Pesquera y Acuícola

## Descripción del proyecto

Este proyecto tiene como finalidad analizar la evolución de los desembarques pesqueros y acuícolas en Chile, utilizando herramientas de programación y análisis de datos.

Se utilizará una base de datos del Anuario Estadístico 2025 del Servicio Nacional de Pesca y Acuicultura (SERNAPESCA), que contiene información histórica sobre desembarques por año, mes, región, puerto, especie y tipo de agente.

## Objetivo general

Analizar la evolución histórica de los desembarques pesqueros y acuícolas en Chile mediante herramientas de programación y análisis de datos.

## Fuente de datos

- **Institución:** Servicio Nacional de Pesca y Acuicultura (SERNAPESCA).
- **Archivo:** `BD_desembarque.csv`.
- **Período informado:** 2000–2025.
- **Formato:** CSV.

## Estructura del proyecto

- `datos/`: archivos de datos originales.
- `src/`: código fuente del proyecto.
- `reportes/`: informes y entregas.
